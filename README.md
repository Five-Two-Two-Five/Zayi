# Zayi

A professional business management application for tracking sales, inventory, expenses, and financial health.

## Overview

Zayi (formerly Egg Trader) is designed for small to medium-sized businesses to manage their daily operations with ease. It features a clean, minimalist UI inspired by modern design patterns and provides powerful insights through interactive charts and semantic data visualization.

## Key Features

- **Multi-Product Management:** Track different types of products with customizable units and sub-units.
- **Sales & Inventory:** Real-time inventory tracking with FIFO (First-In-First-Out) cost calculation for accurate profit reporting.
- **Financial Metrics:** Automated calculation of Revenue, Net Profit, Debt, and Tax Liability.
- **Matte Semantic UI:** At-a-glance financial status using a professional matte color palette.
- **Receipt Generation:** Create and print professional receipts for customers.
- **Expense Tracking:** Categorize and monitor business expenses to maintain a healthy bottom line.
- **Reports & Trends:** Visualize business performance with daily profit trends and expense distribution charts.

## Getting Started

1.  **Clone the repository.**
2.  **Run `flutter pub get`** to install dependencies.
3.  **Run `flutter run`** to start the application on your preferred device.

## Tech Stack

- **Framework:** Flutter (Material 3)
- **State Management:** Riverpod
- **Database:** SQLite (sqflite)
- **Visualizations:** fl_chart
- **Theming:** Custom Instagram-inspired Minimalist Theme
